# Laptop Toolkit v3 — Skytech Noir (Ryzen 7 8845HS / RTX 4070 Laptop)

Программа для Windows 10/11 на русском: диагностика, полная мощность видеокарты (140 Вт),
оптимизация Windows и максимальная автономность от батареи.

## Запуск

1. Распакуйте архив в любую папку (не запускайте прямо из архива).
2. Запустите `LaptopToolkit.bat` и подтвердите запрос прав администратора.

Отчёты сохраняются в папку `LaptopToolkit` на рабочем столе.

## Интерфейс

Тёмная тема с тёмным заголовком окна. Слева — разделы (Главная, Диагностика, Видеокарта 140 Вт, Батарея,
Оптимизация Windows, Безопасность, Тесты, Разгон, Переустановка). Сверху — живые плитки: процессор, память,
батарея (время и расход), видеокарта (нажмите на плитку, чтобы следить за ваттами и температурой).
Действия — карточки с описанием; главные выделены цветом. Внизу — журнал с цветными сообщениями.

## С чего начать

1. **ПОЛНАЯ ПРОВЕРКА** — состояние системы, видеокарты, батареи и питания + отчёт.
2. **140 Вт: разблокировать** — полная мощность RTX 4070 от сети.
3. **Оптимизация Windows** — игры, приватность, реклама, лишние приложения (выбор галочками).
4. **Максимальная автономность** — настройки, которые действуют только на батарее.

## Видеокарта 140 Вт

RTX 4070 Laptop в этом ноутбуке рассчитана на 140 Вт = 115 Вт база + 25 Вт NVIDIA Dynamic Boost.
Кнопка «140 Вт: разблокировать»:

- включает Dynamic Boost (устройство «NVIDIA Platform Controllers and Framework»), если он отключён;
- включает службу NVIDIA Display Container, если её отключил «оптимизатор»;
- ставит режим Windows «Максимальная производительность» от сети и возвращает его при каждом подключении зарядки;
- пробует поднять лимит драйвера до потолка прошивки и показывает итог: доступны ли 140 Вт.

Прошивку видеокарты (vBIOS) программа не трогает: подъём выше заводского потолка — это риск поломки и потеря гарантии.
Dynamic Boost добавляет +25 Вт динамически, когда процессор не загружен полностью, поэтому 140 Вт бывают не всегда.
Проверка — кнопка «Замер пиковой мощности GPU» + игра или FurMark 2.

Для 140 Вт также нужны: питание от сети (родной блок питания), режим Turbo/Performance в фирменной утилите или BIOS,
нормальное охлаждение.

## Батарея

«Максимальная автономность» меняет только настройки для работы от батареи (от сети ноутбук работает на полную):

- турбобуст процессора выключен, приоритет энергоэффективности;
- **автоматически при отключении зарядки:** экран 60 Гц и режим «Лучшая энергоэффективность»;
  при подключении — максимальная частота экрана и «Максимальная производительность»;
- экономия энергии включается сразу на батарее; экран гаснет через 3 мин, сон через 10 мин;
- во сне без интернета, через час сна — гибернация (не разряжается за ночь);
- энергосбережение PCIe, USB, Wi-Fi; экономичное воспроизведение видео;
- браузеры и мессенджеры работают на встроенной графике и не будят RTX 4070;
- Edge не работает в фоне; по желанию — запрет фоновой работы приложений Store.

Автопереключение — задача Планировщика `\LaptopToolkit\PowerAgent`, которая срабатывает на событие Windows
«смена источника питания» и выход из сна. Она не висит в памяти и не тратит заряд в простое.
Журнал срабатываний — кнопка «Журнал автопереключения».

Что батарею садит прямо сейчас: «Что не даёт видеокарте уснуть», «Энергоотчёт», «Расход во сне».

## Откат

Перед каждым изменением программа запоминает исходное значение (`C:\ProgramData\LaptopToolkit\undo.json`).
Кнопки «Откатить настройки батареи» и «Откатить оптимизацию Windows» возвращают всё как было,
кроме удалённых предустановленных приложений (их можно вернуть из Microsoft Store).
Перед оптимизацией Windows программа предлагает создать точку восстановления.

Изменения, сделанные версией v2, этим журналом не отменяются — для них используйте точку восстановления.

## Требования

Windows 10/11, Windows PowerShell 5.1 (встроен в Windows), права администратора.
Для функций видеокарты нужен установленный драйвер NVIDIA.

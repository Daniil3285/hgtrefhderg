# Laptop Toolkit v5 — Skytech Noir (Ryzen 7 8845HS / RTX 4070 Laptop)

Программа для Windows 10/11 на русском: состояние ноутбука, полная мощность видеокарты (140 Вт),
экономия батареи, оптимизация Windows, своя сборка Windows и AI-помощник — всё кнопками и переключателями.

## Запуск

Запустите `LaptopToolkit.exe` и подтвердите запрос прав администратора. Устанавливать ничего не нужно.

При первом запуске Windows может показать «Система Windows защитила ваш компьютер»: exe не подписан
платным сертификатом. Нажмите «Подробнее» -> «Выполнить в любом случае».

Без exe: `LaptopToolkit.bat` рядом с `LaptopToolkit.ps1` (папка с исходниками).

## AI-помощник

Чат, который видит результаты всех проверок программы и отвечает по-русски по шагам.
Сам ничего не меняет — только советует, на какой странице и какую кнопку нажать.

- **Ollama (по умолчанию)** — ИИ прямо на ноутбуке на RTX 4070: бесплатно, без интернета, данные никуда
  не уходят. Кнопка «Установить» в строке «Ollama» скачает программу и модель (~5 ГБ, один раз).
- **Облако** (OpenRouter, OpenAI или любой OpenAI-совместимый сервис) — «Подключение ИИ» -> «Настроить»,
  нужен ключ API. Ключ хранится зашифрованным (DPAPI) только на этом ноутбуке.

## Своя Windows

Своя установочная флешка из **официального** образа Microsoft — собирается на этом же ноутбуке
средствами Windows (DISM), 20–40 минут:

- без рекламы, телеметрии, Copilot, виджетов и предустановленного мусора;
- с драйверами этого ноутбука (Wi-Fi и остальное работает сразу после установки);
- с игровыми настройками и Laptop Toolkit на рабочем столе;
- без обязательной учётной записи Microsoft (локальный пользователь).

Защита Windows и обновления не вырезаются — в отличие от чужих «сборок».
Разделы диска при установке выбираете сами: автоматически ничего не стирается.
Редакция выбирается та же, что сейчас, — Windows активируется сама по цифровой лицензии.
Порядок — на странице «Своя Windows» по шагам 1–4.

## Сборка exe из исходников

`launcher/build.sh` на Linux (mono-mcs, binutils-mingw-w64, gcc-mingw-w64, imagemagick).
Exe — небольшой запускатель на .NET Framework 4 (есть в каждой Windows 10/11) со встроенным
`LaptopToolkit.ps1`; при запуске он распаковывает его в `C:\ProgramData\LaptopToolkit\app` и запускает.

## Как пользоваться

Слева — страницы. Каждая страница **сама проверяет состояние** сразу после запуска программы,
ничего нажимать не нужно. Каждая строка показывает:

- ✓ зелёный — в порядке;
- ! жёлтый — стоит улучшить;
- ✕ красный — проблема;
- справа — кнопка, которая это исправляет, или переключатель «вкл/выкл».

Сверху — живые плитки: процессор, память, батарея (оставшееся время и расход в ваттах),
видеокарта (нажмите на плитку, чтобы следить за ваттами).

| Страница | Что там |
|---|---|
| Главная | Сводка всего ноутбука: что в порядке, что исправить |
| AI-помощник | Чат с ИИ, который видит состояние ноутбука |
| Батарея | Экономия при отключении зарядки — один переключатель |
| Видеокарта | 140 Вт, Dynamic Boost, режим графики, замер мощности, разгон |
| Оптимизация Windows | Переключатель на каждую настройку + «Рекомендуемая оптимизация» |
| Своя Windows | Своя установочная флешка из официального образа Microsoft |
| Диагностика | Сведения о железе и тесты |
| Безопасность | Состояние антивируса и проверки на вирусы |
| Инструменты | HWiNFO, Afterburner, OCCT и др.: «Скачать и запустить» одной кнопкой |
| Журнал | Подробности всех действий, сохранение отчёта |

## Минимальный расход на батарее

Страница «Батарея» → переключатель **«Экономия при работе от батареи»** → включить. Всё.

Дальше программа сама: отключили зарядку — экран 60 Гц, процессор без турбо,
режим «Лучшая энергоэффективность», экономия энергии; подключили — снова полная мощность.
Проверить: отключите зарядку и посмотрите на строку **«Сейчас»** — через 2–3 секунды там будет
«От батареи · 60 Гц · Лучшая энергоэффективность».

Ниже на той же странице — каждая настройка отдельно со своим переключателем и текущим значением.
Главный расход батареи — режим графики «Только дискретная»: строка «Режим графики» подскажет, как переключить.

## Видеокарта 140 Вт

RTX 4070 Laptop здесь — 115 Вт база + 25 Вт NVIDIA Dynamic Boost. Страница «Видеокарта» показывает,
работает ли Dynamic Boost, и кнопкой «Исправить» пытается установить его драйвер. Прошивку видеокарты
программа не трогает. 140 Вт — только от сети и в тяжёлых играх.

## Откат

Каждое изменение запоминается (`C:\ProgramData\LaptopToolkit\undo.json`). Выключили переключатель —
вернулось прежнее значение. «Вернуть всё как было» на странице «Оптимизация Windows» и общий
переключатель на странице «Батарея» откатывают всё сразу (кроме удалённых приложений —
их можно вернуть из Microsoft Store).

## Требования

Windows 10/11, Windows PowerShell 5.1 (встроен в Windows), права администратора.
Для функций видеокарты нужен драйвер NVIDIA, для скачивания программ — winget («Установщик приложений»).
